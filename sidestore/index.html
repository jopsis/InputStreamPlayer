InputStream Player on SideStore

Install and update InputStream Player straight from SideStore, without downloading the IPA by hand on every release.

Add source to SideStore https://jopsis.github.io/InputStreamPlayer/sidestore/apps.json

If the button doesn't open SideStore automatically (for example, when you open this link outside Safari on iOS), add the source by hand:

  1. Open SideStore → Sources tab.
  2. Tap + → Add Source.
  3. Paste the URL above.

Before installing, check the prerequisites: installing SideStore and, if you will run the app inside LiveContainer, installing LiveContainer with SideStore. Verification details and checksums in docs/releases.md (español).

InputStream Player ships no playlists, credentials or third-party keys.
